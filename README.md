# Pragati Tripathi - Professional Astrology Website

This repository contains a responsive one-page website for astrologer **Pragati Tripathi**, designed with a clean and professional visual style.

## Files

- `index.html` - Main website structure and content
- `styles.css` - Site styling and responsive layout
- `script.js` - Mobile navigation and contact form behavior

## Run locally

Open `index.html` directly in your browser, or serve the folder with a static server:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```
