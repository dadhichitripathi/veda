# Vedanga Lumina Prototype

This is a fresh, elegant onboarding-to-results prototype built from the insights in `ONBOARDING_EXPERIENCE_SUMMARY.md`.

## What this prototype demonstrates

- Improved onboarding with inline validation and trust copy
- Consistent phone validation behavior
- Save/retry UX (no silent failure path)
- Moon-sign normalization before personalization lookup
- Crafting experience with interactive cards
- Elegant result cards with actionable recommendations
- Recovery path to edit onboarding details

## Run locally

No dependencies required.

Option 1:
- Open `index.html` directly in your browser

Option 2:
- Serve directory using any static server, then visit `/fresh-elegant-kundali/index.html`

## Notes

- APIs are mocked in `app.js` to keep this prototype self-contained.
- You can replace `mockSaveOnboarding` and `mockGenerateKundali` with real API calls.
